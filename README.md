# Pocket Companion

一个放在桌上的语音小伙伴：说话唤醒或按键，它用一张方形 Nomi 风格的脸回应你。设备直接调用 OpenAI 兼容的 API，中间不需要任何服务器。

![六个表情状态](docs/face-states.png)

从左到右、从上到下依次是：待机、聆听、思考、说话、开心、疑惑。这张图是固件里的 `face.c` 在电脑上直接渲染出来的。

## 架构

```text
┌──────────────────────── 设备（ESP32-S3） ────────────────────────┐
│ 小智固件：唤醒词 / 回声消除 / VAD / 配网 / 屏幕 / 触摸            │
│                                                                  │
│ 录音 ──▶ DirectApiProtocol ──HTTPS──▶ /audio/transcriptions      │
│                │            ──HTTPS──▶ /chat/completions         │
│                │            ──HTTPS──▶ /audio/speech（Ogg Opus） │
│                ▼                                                 │
│ NomiDisplay（表情跟随设备状态和 LLM 情绪）  ◀── 播放              │
└──────────────────────────────────────────────────────────────────┘
```

- 固件底座是 [小智 xiaozhi-esp32](https://github.com/78/xiaozhi-esp32) v2.5.2，以 git subtree 放在 `firmware/`。
- 我们加的代码：
  - 板子适配、表情和界面：`firmware/main/boards/spotpear/spotpear-esp32s3-max35/`（`nomi_ui.c` 和模拟器共用）
  - 直连 API 协议和网页设置页：`firmware/main/protocols/direct_api_*`
  - 启动流程里的开关：`firmware/main/application.cc` 中的 `CONFIG_DIRECT_API`
- 打开 `DIRECT_API`（这块板默认打开）后，设备不连小智服务器，不激活，也不会被官方 OTA 覆盖。

## 硬件

SpotPear ESP32-S3 3.5 寸 AI 板（ESP32-S3R8，8MB PSRAM，480×320 ST7796S，ES8311 + NS4150B，GT911 触摸）。引脚和注意事项见 [docs/hardware.md](docs/hardware.md)；闪存分区、固件余量、哪些操作会清掉数据见 [docs/flash-partitions.md](docs/flash-partitions.md)。

## 使用

1. 烧录固件后，按小智的流程配网：手机连设备热点，在网页里填 Wi-Fi。Wi-Fi 最多存 10 个，设备在哪个网络附近就自动连哪个（都在时连信号强的）；网页设置页的「Wi-Fi 网络」能直接添加和删除，不在身边的也能先存（比如在家先把公司的加好）。开机 60 秒连不上已存网络会自动开配网热点，屏幕上一直挂着提示，「设置 → 网络」里有连热点的二维码。
2. 设备连上网后，屏幕会显示设置页地址。用同一局域网的浏览器打开 `http://设备IP/`。
3. 先添加供应商（选预置的一家或自定义，填 Key；模型列表由设备去供应商那里拉，勾选要用的），再给对话、带图提问、语音识别、语音合成各选一个"供应商 / 模型"。对话模型能看图的话，带图提问选"和对话模型相同"。已存过 Key 的供应商改了地址，必须同时重填 Key。
4. 说「糯米糯米」或按住 BOOT 键说话（设置里可改成点一下开始）。

屏幕操作：

- 左右滑切换四页（翻页时底部有小圆点），从左到右：**历史对话页**（本次开机内聊过的内容，新消息自动更新）、**Nomi 页**（表情和字幕，开机停在这里）、**收听页**（音乐、播客和电台）、**时钟页**（大字时间、日期、天气和接下来的闹钟）
- 从顶部往下拉打开设置，按住底部小白条往上推收起
- 连续对话：叫醒它之后回答完接着听，5 秒没人开口自己回待机；说「退下吧」「今天就聊到这儿」，大模型调 `self.chat.end`，说完那句马上回待机。设置 → 对话里打开**一问一答**，就变成回答完一句就回待机（按住说话本来就是一句一回）
- 闹钟和提醒靠说：「明早 7 点叫我」「每天 7 点半叫我起床」「工作日 9 点提醒我打卡」「25 分钟后提醒我关火」。到点全屏提醒、响铃（睡着、息屏也会亮起来），点「知道了」或按 BOOT 键关掉，「稍后提醒」5 分钟后再响；对话中到点只亮屏不响铃。最多 10 个，断电重启还在；时钟页上点 ✕ 两下删掉，也可以说「把明早的闹钟取消」
- 收听页：顶上切换"音乐 | 播客 | 电台"，左边是正在放的（播客和歌有封面、能拖的进度条、倒回 15 秒 / 快进 30 秒，标题太长一行滚动），右边是正在放的歌的滚动歌词、播客订阅（点进去是最新 10 期）或台单。放着的时候 Nomi 在表情页手放耳边跟着晃，左上角有个"♪ 名字"小条，点一下回收听页；叫它说话时先停，说完接着放（播客和歌从停下的地方接着放），闹钟响时也先停
- 音乐（点歌）：说「放一首晴天」「来首周杰伦的歌」「换一首」。先要在网页设置页的「在线音乐」卡片里填一个音乐网站，只认一种页面格式，见 [docs/online-music.md](docs/online-music.md)；网站失效了换一个同款的填上就行。歌是 MP3 或 m4a，设备看文件头认格式；放完就停，不记进度
- 电台：说「放点音乐」「听中国之声」「换个台」「关掉音乐」，或者点台单。不在台单里的台说名字会去网上的电台目录（radio-browser）搜，满意了说「收藏这个台」；网页设置页的「电台」卡片能添加、删除、试播。默认带 8 个台（千听的 MP3 直播流和 AsiaFM），台单改过一次就存在设备里，刷固件不会变回去，只有恢复出厂才会
- 播客：说「放《忽左忽右》最新一期」「接着听」「快进一分钟」「订阅这个播客」，或者在网页设置页的「播客」卡片搜索订阅、播最新一期。订阅来自 Apple 播客目录（也能直接填 RSS 地址），小宇宙、喜马拉雅的节目都有 RSS；每个播客记着听到哪，下次接着放。节目是 MP3 或 m4a（小宇宙是 m4a，设备自己解析目录、按时间跳）。国外的托管商（比如 fireside）从国内连可能很慢，节目单 20 秒拉不下来就显示加载失败
- 时间开机联网后自动对（北京时间）。天气来自 open-meteo（免 Key），每 30 分钟更新；城市默认按网络位置判断，不对就在网页设置页的「天气」里填，或者直接说「我在深圳」。大模型每轮都知道现在几点、天气和已设的闹钟，问「明天要带伞吗」它能直接答
- 设置 → 声音里有**语音播报**开关（静音模式）：关掉后回复只显示文字，不念出来也不调合成接口；和网页设置页的勾选、对话里说「别念了」让模型关，用的都是同一份设置
- 空闲后先以正常亮度睡着，睡着 30 秒后调暗，到息屏时间关屏；点屏幕唤醒。睡着时默认翻到时钟页当桌面时钟（设置 → 显示 → 睡着时显示，可改回闭眼飘 Z 的表情），被叫醒说话时自动翻回表情页
- 字幕只显示正在念的两行，长句从末尾截取；完整内容看历史对话页

所有接口都是 OpenAI 兼容格式。语音合成必须支持 `response_format: "opus"`。图片按 OpenAI 的 `image_url`（base64 JPEG）发送，gpt-4o、qwen-vl、glm-4v、doubao-vision 等支持图片输入的模型都能用；网页设置页里可以给看图识图单独配一个模型，留空就用对话模型。只支持流式返回的模型（部分 omni 模型）暂时不行。设置页「系统」里的「测试 API」可以检查大模型和 opus 合成。

让它看东西：说「帮我看看」「这是什么」之类的话，大模型会调 `self.camera.look` 工具拍一张（设备端硬件 JPEG 编码，一两秒），照片和问题一起发给视觉模型，回答带着人设说出来。不是实时取景，模型不主动调就不会碰摄像头。

## 编译

需要 ESP-IDF v6.1（小智 2.5 已不支持 5.x）。

```powershell
. C:\Espressif\tools\Microsoft.v6.1.PowerShell_profile.ps1
cd firmware
python scripts/build.py spotpear/spotpear-esp32s3-max35 --language zh-CN
idf.py -p COMx flash monitor
```

## 模拟器

### 整机模拟（设备 + 手机）

在浏览器里把整台设备跑一遍：左边是设备屏幕，跑的是设备上同一份界面代码（`nomi_ui.c` + `face.c`，LVGL 9.5，小智的中文字体），鼠标当触摸，底下是串口日志；右边是一部手机，打开设备的网页。

- 开机流程照固件走：没存 Wi-Fi 就进配网模式，屏幕提示连热点；手机自动弹出配网页（固件里小智 esp-wifi-connect 的同一份 HTML），选 Wi-Fi 填密码（8 位以上算对）
- 联网后启动直连协议，手机打开网页设置页（`direct_api_config_page.h` 的同一份 HTML），填大模型地址和模型后才能对话；没填就按 BOOT 会看到和设备一样的报错
- 右侧圆钮或空格键是 BOOT 键，默认按住说话；开机阶段点一下进配网
- 左右滑切换历史对话 / 表情 / 电台 / 时钟页；顶部下拉打开设置（BOOT 键用法、一问一答、随时插话打断、字幕、人设、音色、亮度、调暗 / 息屏时间、睡着时显示、天气城市、音量、Wi-Fi、已存网络和设置页二维码、测试 API、开配网热点、恢复出厂）
- 收听页用浏览器的 `<audio>` 真的放出声音：播客的节目单、封面经 serve.py 代取，听到哪记在浏览器里（浏览器放不了的流会显示连不上，比如部分 AAC），网页设置页的「电台」卡片和声控换台都能用
- 时钟页用电脑的本地时间（联网后才有，和设备对时一样），天气是假的；「加两个闹钟」「2 秒后响铃」两个按钮看闹钟列表和响铃画面（真机上是跟它说）
- 空闲后睡着翻到时钟页、调暗（按 Z 键立刻睡着），点屏幕唤醒
- 「断电重启」保留设备存储，「清除 Wi-Fi 重启」重走配网，「恢复出厂」全部清空；设备存储存在 `tools/device-sim/.sim-nvs.json`（已忽略，里面有你填的 Key），重启 `serve.py` 也还在
- 「网络环境」：路由器掉线（设备照固件重连 5 次，再按 10 秒起翻倍的间隔扫描；开机 60 秒连不上进配网）、外网不通、API 真实调用 / 模拟回答
- 真实 API：设备由这台电脑代为上网，照 `DirectApiProtocol` 的格式调设置页填的接口（语音识别 → 大模型含工具调用 → 逐句 opus 合成并播放），长期记忆、调音量 / 亮度工具都会生效；浏览器麦克风录音，没有麦克风就在输入框打字（跳过语音识别）

「表情脚本试播」框里点例子或粘一段 JSON，能直接看大模型写的表情会怎么演。模拟器没有摄像头，大模型调 `self.camera.look` 会按"没拍到"的分支回答；屏幕之外的设备行为（联网、对话流程）是照固件代码在模拟器里重写的，不是固件本身在跑。

```bash
# 先编译过一次固件（需要 managed_components 里的 LVGL、小智字体和配网页）
cd tools/device-sim
pip install ziglang
python build.py
python serve.py               # 打开 http://127.0.0.1:8801/
python serve.py --lan         # 可选：同一局域网的真手机也能扫屏幕上的二维码打开设置页
```

## 进度

- [x] 方形 Nomi 表情、板子适配、直连 API、网页设置页（ESP-IDF v6.1 编译通过）
- [x] 浏览器设备模拟器：和设备同一份界面代码，可点、可滑、可下拉设置
- [x] 电池电量显示、空闲闭眼调暗 / 息屏、唤醒词（糯米糯米）
- [x] 唤醒词「糯米糯米」：乐鑫没有现成的 WakeNet 模型，用小智的自定义唤醒词，MultiNet7 中文命令词模型认拼音 `nuo mi nuo mi`，门槛 0.12（板子 config.json 里配，资源分区带 mn7_cn；改了要用 scripts/build.py 重新生成配置、连资源分区一起刷）。MultiNet 每 32ms 要算 11ms，比 WakeNet 重得多，所以只在 VAD 判定有人说话时才喂：安静时存着最近 0.4 秒，开口时补进去，说完再多喂 0.6 秒。AFE 任务固定在核 0，不跟核 1 上的界面抢；建模型时的小块内存临时改放 PSRAM，常驻内部 RAM 反而比 WakeNet 少。试过「嗨诺米」（hai nuo mi），置信度大多在 0.2 上下，不如四个字稳
- [x] 触摸设置页（模拟器里的设置页和设备是同一份代码）
- [x] 视觉识图：大模型按需调 `self.camera.look` 工具拍一张，照片随请求发给支持图片输入的模型（可单独配视觉模型）
- [x] 说话改为 BOOT 键（按住说话 / 点一下）+ 唤醒词；触摸负责切页、下拉设置
- [x] 随时插话打断：焊了 ES7210 的板子用设备端回声消除，说话时开口即打断
- [x] 大模型工具调用：直连 API 桥接设备端 MCP 工具（调音量 / 亮度、查设备状态、看摄像头），模型不支持时自动降级为普通聊天
- [x] 历史对话页：本次开机内聊过的内容左右滑可看，新消息自动更新
- [x] 长期记忆：模型用 `self.memory.remember` 工具记事实，存 NVS（上限 2KB），每轮拼进 system prompt；网页设置页可查看和手改
- [x] 表情脚本：大模型在回复开头写 `<face>JSON</face>`，或调 `self.face.play` 工具，让脸现场表演——眼型（含 NOMI 式空心"0"、螺旋、爱心、墨镜）、眉毛、汗滴、手势、整脸动作，加一个白色线条道具（内置图标或大模型自己画的线条）。格式见 `face_script.h`，模拟器里有试播框
- [x] 语音合成支持 mp3 / wav：先要 opus，服务不支持就自动改要 mp3，设备上用乐鑫音频库解码（真机播放待验证）
- [x] 一问一答开关：设置 → 对话里，打开后回答完一句就回待机；不开是连续对话。说「退下吧」让大模型调 `self.chat.end`，说完那句自动退出聆听（和「闭嘴」区分开——那只是关语音播报）。原来的"连续聆听"开关去掉了：它只是手动开始 / 结束对话，和唤醒词、BOOT 键、5 秒没人说话自动回待机重复
- [x] 网络电台：http(s) 上的 MP3 / AAC 直播流，收流和解码两个常驻任务（栈在 PSRAM），64KB PSRAM 缓冲、攒 1.5 秒再放；放的时候关掉 Wi-Fi 省电（待机的 MAX_MODEM 收不过来），断了 1 / 3 / 6… 秒重连；对话和闹钟时停、连接断开，把内部 RAM 让给语音识别。工具 `self.radio.play`（台单匹配或去目录搜）/ `stop` / `save` / `remove`，台单存 NVS（最多 20 个）
- [x] 翻页流畅度：LVGL 绘制缓冲放 PSRAM（两条 80 行，SPI 直接从 PSRAM DMA，重画区域左右对齐到 32 像素），LVGL 单独 -O2 编译（任务栈加到 9KB），不开小智给 PNG 表情用的 2.5MB 内存池。整屏重画从 90～112ms 降到 60～68ms，空闲内部 RAM 从 35～40KB 到 60KB 以上。屏幕 SPI 试过 80MHz（能到 40～58ms），但这块屏收不稳、画面不跟着变，保持 40MHz
- [x] 播客：订阅（Apple 播客目录搜索或 RSS，存 NVS，最多 10 个）、RSS 只读最新 10 期、每个播客记进度；m4a 自己解析 moov、按时间找帧补 ADTS 头送 AAC 解码器，MP3 按码率算字节位置 Range 跳转；封面（Apple 的小图走 http）JPEG 解码成 88×88。播客的联网全走 esp_http_client（连接、握手有超时，数据在本任务里读，不另开 4KB 内部 RAM 的接收任务），一次只做一件，正在放的若是 https 先让出来（内部 RAM 只够一条 TLS）；栈在 PSRAM 的任务不碰 NVS。工具 `self.podcast.play` / `episodes` / `subscribe` / `unsubscribe` / `seek`
- [x] 时钟页：SNTP 对时（阿里云 / 腾讯 / pool.ntp.org）、open-meteo 天气（http，不占 TLS 内存）、闹钟和倒计时提醒（`self.alarm.add` / `self.reminder.add` / `self.alarm.list` / `self.alarm.remove`，存 NVS）、天气城市（`self.weather.set_city`，与网页设置页共用）；每轮系统提示词带上当前时间、天气和闹钟
